2.1.4 Gegeben sind zwei JavaScript-Programme. Beurteile, inwieweit sich die Programme voneinander unterscheiden. (5 Minuten)

```js

// 
async function sendRequest() {
    let res = await fetch("localhost:5500");
    let data = await res.json();
    console.log(data);
}


//
function sendRequest() {
    fetch("localhost:5500")
    .then(res => res.json())
    .then(data => console.log(data));
}
```

Der beiden Programme Unterscheiden sind lediglich in der Art der Implementierung. Das Ergebnis wird bei gleicher Rückgabe vom Server identisch sein.

In Programm 1 wird async/await verwendet. Das Schlüsselwort await wartet auf das Ergebnis des Promise welches von fetch zurückgegeben wird. In die data-Variable wird das Ergebnis des Funktionsaufrufs von res.json() gespeichert, welches am Ende in der Konsole ausgegeben wird.

In Programm 2 werden Promise-Methoden verwendet. Es wird damit nicht in den synchronen Programmierstil gewechselt (wie bei await), sondern ausschließlich asynchron programmiert. Die erste then-Methode wird aufgerufen, sobald ein Ergebnis vom fetch zurückgeliefert wird. Der von res.json() zurückgegebene Wert wird von der zweiten then-Methode verarbeitet und in der Konsole ausgegeben.

4.3.4
Erkläre welche Anfragetechnik mit dem hier implementierten Server umgesetzt wird und welche Vorteile diese bringt. Hinweis: Wenn die Middleware nicht implementiert wurde, nehme den Text als Beschreibung der Funktionalität. (4 Minuten)

Hier wird die Long Polling Anfragetechnik umgesetzt. 
Der Client sendet eine Anfrage an den Pfad /train, bekommt aber erst dann eine Antwort, wenn eine weitere Anfrage an den Pfad /trainUpdate gemacht wird oder ein Timeout nach zehn Sekunden auftritt. 
Bei einem Timeout stellt der Client direkt wieder eine neue Anfrage an /train, sodass eine Endlosschleife entsteht, die erst durch eine Anfrage an /trainUpdate beendet wird. 
Long Polling hat den Vorteil, dass der Aufwand für den Austausch von HTTP-Anfragen zwischen Client und Server reduziert wird sowie Daten in Echtzeit aktualisiert werden können.

Authentisierung und Authentifizierung
- **_Authentisierung_** ist der Nachweis einer Person, dass sie tatsächlich diejenige Person ist, die sie vorgibt zu sein.  就是自己的身份证
- Methoden der Authentisierung
    - Geheime Informationen, die nur der Person bekannt sind (z.B. Passwort, nicht-öffentlicher Schlüssel)
    - Identifizierungsgegenstand (z.B. Personalausweis)
    - Biometrische Merkmale (z.B. Fingerabdruck)
- **_Authentifizierung_** ist die Überprüfung der behaupteten Authentisierung durch die Person oder Entität gegenüber der die Authentisierung erfolgt ist. 就是别人检查你的身份证
- Beachte: die Begriffe Authentifizierung und Authentisierung werden oftmals synonym verwendet


Vertraulichkeit
- **_Vertraulichkeit_** bezeichnet den Schutz vor unbefugter Preisgabe von Informationen
- Vertraulichkeit einer Nachricht wird erreicht, wenn nur die autorisierten Personen bzw. Entitäten Zugriff auf die Nachricht haben und das Lesen der Nachricht durch Dritte verhindert wird


Integrität
- _**Integrität**_ bedeutet, dass Daten nicht unbemerkt, z.B. durch Angreifer, verändert werden können
- Alle Änderungen an Daten müssen für den Empfänger erkennbar sein
